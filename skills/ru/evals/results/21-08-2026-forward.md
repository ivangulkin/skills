# Independent forward test — 21.08.2026

Цель: проверить semantic behavior готового skill, а не только regex. Каждый
evaluator запускался отдельным subagent с `fork_turns=none` и получал только
путь к skill, реалистичный request, input и output path. Intended answer,
assertions и найденные раньше bugs не передавались.

Outputs создавались в isolated `/private/tmp` и не меняли repository inputs.

## Результаты

| Case | Результат | Deterministic gate | Semantic review |
|---|---|---|---|
| IT Terminology Lock | PASS | `termguard` exit 0 | Удалены только empty opening и promotional conclusion; terms, numbers, causality и `production пока не измеряли` сохранены |
| Already-good IT | PASS | `termguard` exit 0 | Output byte-for-byte равен input; note объясняет no-op |
| Mixed protected spans | PASS | `termguard` exit 0 | Multiline quote, fenced Go code, error string и indented log byte-stable; surrounding filler удалён |
| ADR structural pass | PASS | `termguard` exit 0 | Убраны stated morals/vague reference/clean verdict; facts, index, numbers и unfinished migration сохранены |
| Legal register | PASS | `termguard` exit 0; `slopspans --register legal` clean | Сохранены legal formulas, numbering, 152-ФЗ, deadlines, Service Desk и defined entities; правка не стала blog post |
| Fact-Lock, first run | FAIL | `termguard` exit 0 | Agent добавил новый measurement plan: batch size, peak memory и detailed timings. Regex gate закономерно этого не увидел |
| Fact-Lock after invariant fix | PASS | `termguard` exit 0 | Остались только source plans `streaming` и `COPY вместо INSERT`; missing quantitative data помечены «нужно измерить» без нового experiment checklist |

## Исправление после fail

В `SKILL.md` добавлен запрет превращать просьбу «добавь конкретики» в новый
measurement plan, metrics, experiments, acceptance criteria или action items.
Detailed planning разрешён только отдельным request. Assertion добавлен в
`evals/evals.json`.

Fail важен: он показывает границу `termguard`. Checker ловит numbers, URLs,
protected spans и explicit terms, но не может распознать новый causal claim,
status или prose-only plan. Semantic eval остаётся обязательным.

## Команды deterministic проверки

Каждый source/edit pair проверялся так:

```text
python3 scripts/termguard.py \
  SOURCE EDITED --terms-file LOCKED_TERMS
```

Legal output дополнительно:

```text
python3 scripts/slopspans.py \
  --register legal EDITED
```

## Ограничения

- Это семь runs одного agent family, а не reader study.
- Проверены выбранные fixtures, не все возможные IT domains и registers.
- Termguard не доказывает semantic equivalence.
- Trigger cases остаются declarative model eval, а не keyword classifier.

Forward test подтверждает acceptance criteria на текущих cases и фиксирует один
реальный fail/repair cycle; он не даёт aggregate quality score.
