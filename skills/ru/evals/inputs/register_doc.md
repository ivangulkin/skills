# Подключение к API платёжного шлюза

Если Вы используете SDK, ключ подставится автоматически. Вы можете передать его и
вручную, через заголовок `Authorization`.

Вы должны передать заголовок `X-Request-Id` в каждом запросе. Если шлюз вернул
`429`, перезапусти клиент и повтори запрос позже.

## Требования к клиенту

Требования этого раздела следуют RFC 2119.

- Клиент должен повторить запрос с тем же `X-Request-Id`, если соединение
  оборвалось.
- Клиенту следует выдерживать паузу не меньше секунды между повторами.
- Клиент может кешировать ответ `GET /rates` на 60 секунд.
