# ratelimit

## Введение

В современном мире высоконагруженных систем важную роль играет ограничение
частоты запросов. Данная библиотека представляет собой мощное и гибкое
решение для контроля нагрузки, которое легко интегрируется в любой проект.
Стоит отметить, что она поддерживает несколько алгоритмов.

## Возможности

- **Быстрый** — работает быстро
- **Гибкий** — легко настраивается
- **Надёжный** — проверен временем

Библиотека подходит для всего: от небольших скриптов до сложных
распределённых систем. Многие разработчики отмечают удобство API.

## Установка

Установка осуществляется через менеджер пакетов. Процесс установки является
достаточно простым и не требует дополнительной настройки.

```
go get github.com/acme/ratelimit
```

## Использование

Создайте лимитер и вызывайте `Allow`. Метод возвращает булево значение,
подчёркивая простоту интерфейса.

```go
lim := ratelimit.New(100, 200)
if !lim.Allow("user-42") {
    return ErrTooManyRequests
}
```

Первый параметр — скорость пополнения, второй — размер бакета. Современные
подходы к ограничению нагрузки рекомендуют подбирать эти значения под профиль
трафика.

## Ограничения

Для честной очереди это не тот инструмент. Также следует учитывать, что при
высокой конкуренции возможны просадки производительности.
