# ru

Свод правил русского письма и редактуры. Рабочие инструкции — [SKILL.md](SKILL.md);
здесь только то, что нужно тому, кто **меняет сам скилл**.

Второй копии правил в этом файле нет и быть не должно: одно правило живёт в одной
карточке, всё остальное на неё ссылается.

## Устройство

| Каталог | Что там |
|---|---|
| `references/` | карточки правил, по одному предмету на файл |
| `evals/` | случаи разработки, определения поведенческих задач и тесты инструментов |
| `scripts/` | необязательный инструмент проверки артефактов |
| `integration/` | подключение к клиентам, постоянное ядро, отключение |
| `maintainers/` | доказательная база, разбор чужих реализаций — не для правки текста |
| `agents/` | видимое имя и политика вызова для Codex |

Каталог скилла самодостаточен: манифеста плагина и вложенных `SKILL.md` здесь не
создаётся.

## Правило, по которому принимается новое правило

Из [maintainers/evidence.md](maintainers/evidence.md), и оно обязательное:

1. устойчивый идентификатор, свободный во всём дереве;
2. источник с параграфом либо точное редакторское основание;
3. дата проверки внешнего источника;
4. три примера: срабатывание, несрабатывание, граница;
5. где правило выключено — регистр, поверхность, условия конструкции;
6. что находка доказывает и чего не доказывает.

Правило без обновлённых примеров считается незаконченным.

## Проверки перед коммитом

```bash
python3 -m unittest discover -s evals -p 'test_*.py'
python3 scripts/validate_skill.py
```

Плюс то, что тестами не ловится и проверяется глазами:

- нет висячих ссылок на идентификаторы правил;
- нет второй формулировки одного предписания в двух файлах;
- у каждой новой карточки есть раздел «не трогать».

## Чего в этом скилле нет намеренно

Сводной оценки текста, вердикта об авторстве, обхода детекторов, числовых порогов
плотности знаков, списков запрещённых слов и синтетических «признаков живого
письма». Причины — в [maintainers/prior-art.md](maintainers/prior-art.md),
раздел Reject.
