# Duo Codex to Gemini: парный разбор с Gemini / Antigravity

Gemini (`agy`) — оппонент. Один тред Codex ведёт **одну постоянную беседу** в Antigravity: сначала вы можете согласовать замысел (`--phase design`), а после реализации — проверить код в той же беседе (`--phase review`), где у Gemini в контексте остаются его собственные прежние возражения `p0`/`p1`. Ревью без предварительной фазы дизайна тоже работает — беседа просто создаётся на первом вызове.

В самой среде Antigravity / Gemini этот скилл исключён в `~/.gemini/config/skills.json` (для обратного направления из Gemini в Codex используется `duo-gemini-to-codex`).

```bash
# путь, а не команда: zsh не разбивает переменную на слова, и "python3 …"
# одной строкой превратился бы в имя несуществующей программы
DUO="$HOME/.codex/skills/duo-codex-to-gemini/scripts/duo"
python3 "$DUO" verify      # ничего не тратит; всё, что можно проверить до первого токена
```

## Выбор фазы

Фаза передаётся флагом `--phase` под капотом в зависимости от запроса человека:

| Запрос человека | Фаза | Что делает оппонент |
|---|---|---|
| «составь дизайн», «спланируй изменения», «согласуй план», «договоритесь» | `--phase design` | Ищет, что в замысле не учтено, где предположение выдано за факт, что развалится на границах |
| «проведи ревью», «отдай на ревью», «проверь сделанное» | `--phase review` | Проверяет реализацию против задачи и собственных прежних `p0`/`p1` в той же беседе |

## Шаги раунда

1. **Подготовь бриф.** Напиши сообщение по шаблону [`brief-template.md`](references/brief-template.md) в файл `$TMPDIR/duo-<phase>-<n>.md` во временном каталоге сессии, а не в репозитории:
   - Для `design`: заполни все шесть разделов, укажи файлы путями (не вставляй простыни кода), в разделе «где не уверен» сформулируй хотя бы один настоящий вопрос.
   - Для `review`: укажи ветку, диапазон коммитов и команду для получения `git diff` (вставлять diff целиком можно только если он короче экрана; Gemini сам читает репозиторий), а в разделе 6 — границы проверки.

2. **Запусти раунд.** Ход идёт минутами, запускай с явным `--request-id`:

   ```bash
   RID=$(uuidgen | tr A-Z a-z)   # запомни: он нужен для повтора и для подтверждения
   python3 "$DUO" ask --phase design --message-file "$TMPDIR/duo-design-1.md" --model 'pro high' --request-id "$RID"
   ```

   Для быстрого прогона есть `--model 'flash low'` или `--profile test`; для глубокого разбора и ревью по умолчанию используется профиль `default` (`gemini-4-argon` с усилием `high`).
   Если вывод потерян или ход прерван — повтори команду с **тем же** `--request-id`: ответ воспроизведётся из state или дособерётся из транскрипта `brain/<conversation_id>`, второй ход не уйдёт.

3. **Разбери возражения по `id`.** Когда в выводе строка `ПРОДОЛЖАТЬ:`, каждое блокирующее возражение (`p0`/`p1`) требует ответа в разделе 5 следующего брифа:
   - На фазе `design`: `принято` (что изменилось в плане), `отклоняю` (с доказательством по коду или фактам) либо `снято`.
   - На фазе `review`: либо исправление в коде отдельным коммитом и `принято` со ссылкой на коммит, либо `отклоняю` с доказательством. Вердикт никогда не принимается пакетом.
   Следующий вызов запускай с `--ack-request-id "$RID"` и новым `--request-id`. Возвращайся к шагу 2.

4. **Остановись на человека.** Когда вывод сказал `ИТОГ:`, покажи человеку картину целиком:
   - На фазе `design`: итоговый план, что Gemini принял, что осталось спорным, и обе позиции по каждому спорному пункту без выбора за человека. Работа начинается только после подтверждения человека.
   - На фазе `review`: что исправлено, что подтверждено и что осталось спорным с обеими позициями.

5. **Покажи беседу.** После завершения фазы дай человеку строку `смотреть: agy --app_data_dir=antigravity --conversation <id>` из вывода.

## Как выглядит ответ

По умолчанию — `--verdict-format trailer`, и переключать его на `json` не нужно:
Gemini всегда отвечает сначала понятной человеку прозой, а в самом конце
прикладывает один блок ```json с вердиктом (для робота). Формат `json` оставляет
только голый JSON без прозы — в обычных раундах его не используй.

Вердикт: `stance` (`agree` / `disagree` / `needs_info`), `stop`, `confidence`,
`summary`, `findings[]` с `id`, `severity` `p0`–`p3`, `claim`, `evidence`,
`response` (`new` / `confirm` / `dispute` / `retract`), `rationale`, и
`open_questions[]`. Возражение с `!` в выводе держит цикл: `p0`/`p1` в
состоянии `new` или `dispute`.

## Правило остановки

Потолок `--max-rounds` (3), досрочный выход только после `--stop-hold` (2)
согласных раундов подряд. Итоги:

| `ИТОГ:` | Что значит |
|---|---|
| `converged` | согласие продержалось два раунда |
| `agreed_unheld` | последний раунд чистый, но два подряд не набралось |
| `stable_disagreement` | те же блокирующие возражения два раунда подряд, либо потолок с открытыми |
| `needs_info` | потолок, оппонент ждёт ответов на `open_questions` |
| `max_rounds` | потолок без согласия и без открытых блокеров |
| `unparseable` | оппонент не дал разбираемый вердикт до конца |

Согласие двух моделей — рекомендация. Решение и запуск — за человеком.

## Модель и усилие

```bash
python3 "$DUO" models                                    # каталог моделей Antigravity
--model 'pro high'         --model 'argon medium'        # gemini-4-argon (Pro)
--model 'flash low'        --model 'flash medium'        # gemini-3.8-flash
--model 'opus high'        --model 'sonnet medium'       # claude-opus-5-5 / claude-sonnet-5-5
--effort high                                            # low | medium | high
--profile test                                           # gemini-3.8-flash / low; default — gemini-4-argon / high
```

Если передать слитный слаг вроде `--model gemini-4-argon-medium` вместе с
`--effort high`, скрипт сам нормализует их в базовую модель `gemini-4-argon` и
`--effort high`, чтобы CLI `agy` не отверг вызов из-за конфликта суффикса.

## Состояние и разрешение сессии Codex

Файл `~/.codex/state/duo/<ключ>.json`. Ключ — `CODEX_THREAD_ID` текущего треда
Codex. Если `duo` вызван из дочернего субагента Codex, скрипт проходит по
таблице `thread_spawn_edges` в `~/.codex/state_5.sqlite` до корневого треда,
чтобы субагент продолжал ту же беседу Gemini, что и родительский тред.

Каталог беседы берётся из колонки `cwd` таблицы `threads` в
`~/.codex/state_5.sqlite`, а заголовок — из `~/.codex/session_index.jsonl` (или
`threads.title` с очисткой IDE-префиксов) и записывается в
`~/.gemini/antigravity/conversation_summaries.db`.

## Другие команды

```bash
python3 "$DUO" status           # беседа этой сессии, модель последнего раунда, фазы
python3 "$DUO" schema           # схема вердикта
python3 "$DUO" close            # забыть связь сессии с беседой
python3 "$DUO" ack <request-id>  # подтвердить раунд, не начиная следующий
python3 "$DUO" recover --from <старый ключ>   # перенести связь под текущий ключ
python3 "$DUO" repair-redirect <ключ>        # убрать в сторону нечитаемый редирект
```
